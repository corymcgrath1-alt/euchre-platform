Euchre Club 1.0

Support

Euchre Club is an offline solo game. Most play, save, resume, and review problems can be diagnosed without sharing private device information.

Include with a request

  • App version and build number from Settings.
  • Practice seed, if the game used one.
  • The game phase and action you attempted.
  • Whether the app had just resumed from the background.

Local recovery

Return Home and choose Resume Game to reconstruct the active game from its ordered move history. Reset Local Data is destructive and should be used only after other recovery steps.

Contact

Open a support request in the public repository. Do not post private device, Apple account, signing, or payment information.
